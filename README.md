# CONQUEST-Map

世界各地「制霸地圖」合集 —— 純靜態單頁應用，點選地圖、記錄旅程、累積分數、解鎖成就、升級等級。所有資料只存於本機瀏覽器（localStorage），無雲端。

倉庫根目錄的 [index.html](./index.html) 是總入口頁，用瀏覽器打開即可選擇要查看的制霸地圖。

## 運行方式

瀏覽器安全策略禁止 `file://` 頁面 fetch 本地資源，任選其一：

1. **本地伺服器（推薦）**：在項目根目錄執行
   ```
   python3 -m http.server 8000
   ```
   然後訪問 `http://localhost:8000/<項目目錄>/`
2. 直接雙擊各項目 `index.html`：頁面會提示手動選擇資源載入（FileReader 讀取）。

## 通用功能

- 地圖點選 → 側邊面板：在地美食 / 名所景點 / 節慶行事 + 上傳旅途照片 + 星級評分
- 旅程記錄：途經 / 遊玩 / 住宿 / 長居，可填日期、評分、心得、勾選成就
- 計分：最高造訪層級計分 + 重複造訪 + 地區制霸加成 + 成就加成
- 成就系統、等級系統、願望清單、隨機探索、搜尋定位
- 制霸戰報：複製文字 / 匯出圖片 / 匯出資料檔 / 從檔案匯入
- 好友排行、多地圖管理（識別碼 + 編輯密碼鎖）
- 多語言切換（繁體 / 簡體 / 日本語 / English，localStorage 持久化）

各項目的儲存命名空間互不干擾（如 `usaMap.*` / `japanMap.*`），可在同一瀏覽器並存。
