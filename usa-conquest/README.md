# USA Conquest Map · 美國制霸地圖

基於「日本制霸地圖」移植開發的美國版：50 州 + 華盛頓特區（共 51 個州級單位）的
制霸記錄器。點選地圖、記錄旅程、累積分數、解鎖成就、升級等級。純靜態版，
所有資料只存於本機瀏覽器（localStorage），無雲端。

## 目錄結構

```
usa-conquest/
├── index.html            # 入口頁面（單文件應用，含全部邏輯與 i18n）
├── assets/
│   ├── usa_geojson.js    # 美國州界 GeoJSON（真實經緯度，AK/HI 已預置為插圖）
│   └── states/           # 51 張州風景圖（01_alabama.jpg … 51_dc.jpg）
└── scripts/
    ├── build_geojson.py  # 原始州界 → 編號/插圖處理腳本
    └── build_usa.py      # 州數據與 HTML 生成腳本
```

## 運行方式

瀏覽器安全策略禁止 `file://` 頁面 fetch 本地資源，任選其一：

1. **本地伺服器（推薦）**：在項目根目錄執行
   ```
   python3 -m http.server 8000
   ```
   然後訪問 `http://localhost:8000/usa-conquest/`
2. 直接雙擊 `index.html`：頁面會提示手動選擇資源載入（FileReader 讀取）。

## 功能（與日本版一一對應）

- 地圖點選 → 右側面板：在地美食 / 名所景點 / 節慶行事 + 上傳旅途照片 + 星級評分
- 旅程記錄：途經(+2) / 遊玩(+5) / 住宿(+10) / 長居(+20)，可填日期、評分、心得、勾選該州成就
- 計分：最高造訪層級計分 + 同州重複造訪(+2) + 地區制霸加成（4 大人口普查地區：全訪 +10、全數住宿以上 +15）+ 成就加成
- 成就系統：40 項美國主題成就（國家公園巡禮、大峽谷與紅岩、66 號公路、殖民十三州、迪士尼雙城等），自動判定 + 手動勾選
- 10 級等級：初到美洲 → 傳說的旅人
- 願望清單、隨機探索、搜尋定位（中文／英文／日文／地區）
- 制霸戰報：複製文字 / 匯出圖片 / 匯出資料檔 / 從檔案匯入
- 好友排行：匯入好友資料檔，本機比拚
- 多地圖管理：識別碼（USA-XXXX）+ 編輯密碼鎖
- 四語切換：繁體 / 簡體 / 日本語 / English（localStorage 持久化）

## 資料說明

- 州界 GeoJSON 來源：PublicaMundi（US States），已移除波多黎各並補入華盛頓特區，
  阿拉斯加與夏威夷按美國地圖慣例縮放平移為插圖；渲染邏輯與業務數據解耦。
- 州資料：每州包含繁中 / 日文 / 英文名稱、所屬地區、一句話簡介、在地美食、
  名所景點、節慶行事。
- 儲存命名空間：`usaMap.*`、語言鍵 `us_lang`，與日本版（`japanMap.*` / `jp_lang`）
  互不干擾，可在同一瀏覽器並存。
