HOW IT WORKS
1
Erstelle deine Eroberungskarte
Vergib einen Namen und optional ein Bearbeitungspasswort – du erhältst einen persönlichen Code. Diese statische Version hat keine Cloud: Code und Passwort liegen nur in diesem Browser. Screenshot als Backup empfohlen.
2
Klicke auf die Bundesländer
Wähle ein Bundesland auf der Karte – im Panel rechts findest du regionale Küche, Sehenswürdigkeiten und Feste.
3
Trage jede Reise ein
Wähle je Besuch „Durchreise / Besuch / Übernachtung / Wohnen“, ergänze Datum, Bewertung und Notizen und hake dort erreichte Erfolge ab.
4
Sammle Punkte, steige auf
Je höher das Besuchs-Level, desto mehr Punkte. Wiederbesuche, komplette Regionen und besondere Erfolge bringen Extrapunkte.
5
Teile deinen Bericht
Erzeuge mit dem Bericht-Button Text und Bild deines Eroberungsstands oder exportiere die Daten, um auf einem anderen Gerät weiterzumachen.

Jedes Bundesland zählt, sobald eine Reise eingetragen ist – je höher das Level, desto mehr Punkte. Wer alle Länder einer Region bereist, erhält den „Region komplett“-Bonus, wer überall mindestens übernachtet hat, noch einen Extra-Bonus. Besondere Erfolge geben weitere Punkte. Pro Land zählt das höchste Besuchs-Level.
